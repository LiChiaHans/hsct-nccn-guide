# 造血幹細胞移植 (HSCT) — NCCN v1.2025 臨床速查手冊

依據 **NCCN Clinical Practice Guidelines in Oncology: Hematopoietic Cell Transplantation (Version 1.2025 — February 28, 2025)** 整理與繁體中文翻譯之臨床速查網站。

## 功能特色

- **章節快速導覽與全文檢索**：側邊欄章節目錄、頂部快速跳轉標籤，按 `/` 快速全文高亮搜尋。
- **三大臨床互動計算機**：
  1. 調理化療 **25% / 40% 調整體重 (ABW)** 計算機（HCT-A 7/10）
  2. 急性 GVHD **MAGIC 分期與分級** 計算機（GVHD-A）
  3. 慢性 GVHD **NIH 整體嚴重度** 計算機（GVHD-C）
- **完整 NCCN v1.2025 重點**：含 Treosulfan MA 調理、VOD/SOS 與 Defibrotide、Sirolimus + prednisone 與 FAM 治療慢性 GVHD、uhCG/EGF、Ruxolitinib / Ibrutinib / Belumosudil / Axatilimab-csfr 實證整理。
- **跨站連結**：內建回到血液科入口網首頁按鈕、淺色／深色模式切換，並直連 **WHO 第 5 版血液腫瘤分類網頁**與各疾病個論。
